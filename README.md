# 打卡日記 · Timecard

個人用的線上打卡系統 + 小日曆記事本。
手機優先、淺色大地色系、液態玻璃(霧面/水霧)介面。
前端純靜態 → 放 **GitHub Pages**;資料 → **Firebase Firestore**。全程可零成本。

---

## 檔案結構

```
girlfriend/
├─ index.html               介面骨架(登入 / 首頁 / 紀錄 / 日曆 / 設定 + 三個 Sheet)
├─ manifest.webmanifest     PWA 設定(可加到手機桌面當 App 用)
├─ sw.js                    Service Worker,離線也打得了卡
├─ firestore.rules          Firestore 安全規則(務必貼上)
├─ css/
│   └─ style.css            大地色 + 液態玻璃樣式
├─ js/
│   ├─ firebase-config.js   ★ 只有這支要你填東西
│   ├─ store.js             資料層(Firestore / 本機 自動切換、寫入防抖省額度)
│   ├─ calc.js              工時、加班、計薪週期、CSV 的計算核心
│   └─ app.js               介面互動、動畫、渲染
└─ icons/                   PWA 圖示
```

## 一、Firebase 設定(約 5 分鐘)

1. 到 <https://console.firebase.google.com> → **新增專案**(方案選免費的 Spark 即可)。
2. 左上角 `</>` **新增網頁應用程式** → 隨便取名 → 註冊。
3. 複製它給你的 `firebaseConfig`,整段貼進 `js/firebase-config.js` 覆蓋原本的假值。
4. 左側 **Authentication** → 開始使用 → 登入方式 → 啟用 **電子郵件/密碼**。
5. 左側 **Firestore Database** → 建立資料庫 → 位置選 `asia-east1`(台灣最近)。
6. 進 **規則** 分頁 → 把 `firestore.rules` 全部內容貼上 → **發布**。
7. **Authentication → 設定 → 已授權網域** → 加入你的 GitHub Pages 網域
   (例:`你的帳號.github.io`),不然登入會被擋。

> 還沒設定也能用:程式會自動退回「本機模式」,資料存在手機瀏覽器裡,
> 填好設定後再登入即可改用雲端。

### 資料結構

```
users/{uid}/meta/settings        時薪、發薪日、加班規則…
users/{uid}/days/2026-08-30      {
                                   date:  "2026-08-30",
                                   events:[{t:"in",ts:1756...,manual:false,geo:{...}}, …],
                                   note:  "小日曆記事",
                                   leave: {type:"annual",hours:8,note:""}
                                 }
```

一天只有一份文件,打卡/記事/請假共用 → 讀寫次數壓到最低。
再加上 **寫入防抖 0.7 秒 + writeBatch 合併**,連按幾下也只算一次寫入,
免費額度(每日 5 萬讀 / 2 萬寫)一個人用一輩子都用不完。

## 二、上傳到 GitHub Pages

```bash
cd "d:/Claude Project/girlfriend"
git init
git add .
git commit -m "打卡日記 v1"
git branch -M main
git remote add origin https://github.com/<你的帳號>/<repo 名>.git
```

手機開啟後選「加到主畫面」,就是一支真的 App(可離線、有圖示)。

## 四、計薪週期算法(比照企業作法)

設定裡有三種模式:

| 模式 | 期間 | 適用 |
|------|------|------|
| **發薪日往前推一個月**(預設) | 發薪日 5 號 → **上月 5 號 ~ 本月 4 號** | 你描述的算法 |
| 當月 1 號 ~ 月底 | 1 號 ~ 月底,次月 5 號發 | 最常見的月結 |
| 自訂結算起始日 | 例如 21 號 ~ 次月 20 號 | 大型製造/服務業常見 |

實際範例(發薪日 5 號):

```
2026/07/05 ~ 2026/08/04  →  2026/08/05 發薪
2026/08/05 ~ 2026/09/04  →  2026/09/05 發薪   ← 現在正在累積這一期
```

法規依據(勞動部《勞雇雙方約定工資給付日及工資給付指導原則》):

* 工資**計算週期不得超過一個月**。
* 發薪日**最晚為計薪週期屆滿後 15 日內**;遇假日只能提前、不能延後。
* 勞動部目標:2026 年底前 99 人以下公司於週期屆滿後 **7 日內**、
  100 人以上 **5 日內** 給付。

### 加班費

比照《勞基法》第 24 條(設定裡可關閉):

| 區間 | 倍率 |
|------|------|
| 每日約定工時內(預設 8 小時) | 1.0 |
| 延長工時前 2 小時 | **1.34** |
| 第 3 小時起 | **1.67** |

薪資 = `(工作秒數 ÷ 3600) × 時薪`,**全程用秒計算,最後才進位到元**,
所以「上午 03:02:29 下班」這種零碎時間也算得出來。

### 請假給薪

| 假別 | 預設給薪 | 可調 |
|------|----------|------|
| 特休 / 國定假日 | 100% | ✅ |
| 公假 | 100% | 固定 |
| 病假(普通傷病假) | 50% | ✅ |
| 事假 | 0% | ✅ |
| 例假 / 休息日 | 不計薪 | — |

## 五、額外加上的企業級功能

參考市面上的雲端差勤系統(104 企業大師、FemasHR 等)後補上的:

* **缺卡自動偵測** — 過去 14 天有上班沒下班會跳提醒,日曆該格變橘色。
* **GPS 定位打卡** — 可開關;打卡瞬間背景記座標,不會拖慢按鈕反應。
* **補卡稽核軌跡** — 補登紀錄永久標「補」並保留原因,和正常打卡分得開。
* **午休自動扣除** — 設定分鐘數後,忘記按休息也會自動扣(有實際打卡則以實際為準)。
* **打卡 × 日曆合一** — 同一天的工時、假別、記事在同一張卡片,不用切換兩個 App。
* **CSV 匯出** — 帶 BOM,Excel / Google 試算表直接開不亂碼,可拿去對帳。
* **PWA 離線可用** — 沒訊號照樣打卡,恢復連線自動補傳。
* **多段上下班** — 一天可以打好幾次上下班(外出、跨夜),狀態機自動配對。

## 七、常見狀況

**Q:按了上班卻沒反應?**
A:同一天已經在上班中會擋下來並提示。要重打請到日曆點該天 → 刪掉那筆紀錄。

**Q:跨夜班怎麼算?**
A:工時算在「按下上班那一天」。半夜 03:02:29 下班,會記在前一天的紀錄裡。

**Q:換手機資料會不會不見?**
A:用 Email 登入就在雲端;若選「先不登入」則只存在該台手機。

**Q:Firebase 會不會被收錢?**
A:Spark 免費方案沒有綁信用卡就不會扣款,額度用完只會暫停不會計費。
